## 1. 参考书策略：三条线，各司其职

一本教材同时承担"术语权威 + 内容好看 + 能抄图表"三个角色是不现实的，所以拆成三条线。

### 线 1 · 术语与知识顺序：李重光《音乐理论基础》（人民音乐出版社）

选它的理由不是它写得最有趣（实际上它相当枯燥），而是**它是中文乐理的标准话语体系**。
中文乐理考试、大部分教材、以及以后查到的中文资料，用的都是这套术语和这套讲解顺序
（音高 → 时值 → 节奏节拍 → 音程 → 和弦 → 调式 → 调性）。
跟着它走，读者学完之后能无障碍地看懂其他中文资料。

它的短板正好是本项目的发力点：**它只有文字和静态谱例，没有听觉设计**。
我们保留它的骨架，把每一节都换成一个能玩的东西。

### 线 2 · 引用与图表素材：Open Music Theory, 2nd ed.

[openmusictheory.github.io](https://openmusictheory.github.io/) —— 开放许可（CC BY-SA），
可以合法改写、引用、放图表。结构比李重光现代（fundamentals → 和声 → 曲式），
英文术语可以拿来给中文术语做对照标注。

**这是本项目唯一能直接引用内容的参考书**，其他书都只能"参考其知识顺序与术语体系"。

### 线 3 · 交互语言：现有产品（只学方法，不抄内容）

| 产品 | 学什么 |
| --- | --- |
| Chrome Music Lab | 具象化交互的标杆：一个概念一个玩具，界面极简，零文字也能玩 |
| Ableton Learning Music / Learning Synths | 教学节奏与文案：先玩再解释，每小节一个明确的小胜利 |
| Hooktheory | 和弦进行的具象化与"为什么好听"的即时反馈 |
| musictheory.net | 练习题型设计，尤其是听辨题的量与难度梯度 |
| Tonnetz（音网） | 和弦／调性关系的二维空间模型 |

## 2. 版权纪律

- **不复制**任何受版权保护教材的文字、谱例、图表、习题；
- 采用的只有"知识顺序"和"术语体系"——术语和知识点本身不受版权保护；
- Open Music Theory 的内容若改写使用，需署名并以相同方式共享；
- **分析现代作品（第三、四部分）时**：不放原曲音频、不放原谱截图，
  实验台里的素材一律标明"本站自己写的示意"，需要试听时只给合法来源的链接；
- 所有谱例、图形、声音由本项目生成（Web Audio 实时合成 + SVG 自绘 + MuseScore 命令行渲染），
  不引入第三方素材。
