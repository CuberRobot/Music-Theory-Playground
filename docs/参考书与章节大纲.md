> 先在纸上把"讲什么、按什么顺序讲、每一章的主玩法是什么"定下来，再动手写代码。
> 每章的主玩法必须能落到 [UI设计规范.md](UI设计规范.md) 第 6 节的隐喻系统里。

## 1. 参考书策略：三条线，各司其职

一本教材同时承担"术语权威 + 内容好看 + 能抄图表"三个角色是不现实的。所以拆成三条线：

### 线 1 · 术语与知识顺序：李重光《音乐理论基础》（人民音乐出版社）

选它的理由不是它写得最有趣（实际上它相当枯燥），而是**它是中文乐理的标准话语体系**。
中文乐理考试、大部分教材、以及你以后查到的中文资料，用的都是这套术语和这套讲解顺序
（音高 → 时值 → 节奏节拍 → 音程 → 和弦 → 调式 → 调性）。
跟着它走，读者学完之后能无障碍地看懂其他中文资料。

它的短板正好是本项目的发力点：**它只有文字和静态谱例，没有听觉设计**。
我们保留它的骨架，把每一节都换成一个能玩的东西。

### 线 2 · 引用与图表素材：Open Music Theory, 2nd ed.

[openmusictheory.github.io](https://openmusictheory.github.io/) —— 开放许可（CC BY-SA），
可以合法改写、引用、放图表。它的结构比李重光现代（fundamentals → 和声 → 曲式），
英文术语可以拿来给中文术语做对照标注。

**这是本项目唯一能直接引用内容的参考书**，其他书都只能"参考其知识顺序与术语体系"。

### 线 3 · 交互语言：现有产品（只学方法，不抄内容）

| 产品 | 学什么 |
| --- | --- |
| **Chrome Music Lab** | 具象化交互的标杆。一个概念一个玩具，界面极简，零文字也能玩 |
| **Ableton Learning Music / Learning Synths** | 教学节奏和文案。先玩再解释，每小节一个明确的小胜利 |
| **Hooktheory** | 和弦进行的具象化与"为什么好听"的即时反馈 |
| **musictheory.net** | 练习题的题型设计，尤其是听辨题的量与难度梯度 |
| **Tonnetz（音网）** | 和弦/调性关系的二维空间模型，可直接用作第 8 章的隐喻 |

### 版权纪律

- **不复制**任何受版权保护教材的文字、谱例、图表、习题。
- 采用的只有"知识顺序"和"术语体系"——术语和知识点本身不受版权保护。
- Open Music Theory 的内容若改写使用，需署名并以相同方式共享。
- 所有谱例、图形、声音由本项目生成（Web Audio 实时合成 + SVG 自绘），不引入第三方素材。

### 第 0 章 · 声音与泛音（前置章）

- **参考**：缪天瑞《律学》（音的性质、泛音列）；李重光"音的产生与性质"
- **核心概念**：音的四要素（高低/长短/强弱/音色）、乐音与噪音、泛音列、音色的成因
- **主实验台**：**泛音列实验室** —— 一条基频 + 8 个可开关的泛音滑块，实时相加成波形
- **玩法**：拖动泛音配比，音色从"长笛"变到"小号"；关掉基频，发现音高居然还在
- **挑战**：给一个音色，判断哪个泛音被加强了
- **为什么放最前**：它回答了"声音到底是什么"，后面所有内容都站在这个地基上。
  而且它最好玩，适合当作第一印象。

---

### 第 1 章 · 音高与乐音体系

- **参考**：李重光 第一章 音（乐音体系·音列·音级 / 音名·唱名 / 音组 / 标准音 / 十二平均律 / 半音与全音 / 等音 / 音域与音区）
- **核心概念**：音名 CDEFGAB、唱名 do re mi、音组与中央 C、A4 = 440Hz、半音与全音、十二平均律、**等音（同音异名）**、音域与音区
- **主实验台**：**音高螺旋** —— 螺旋上升一圈回到同名音
- **玩法**：沿螺旋拖动，键盘、五线谱、频率数值三处同步；把"升 C"和"降 D"折叠到同一个点，
  标签翻转，听到是同一个音
- **挑战**：给频率判音名；判断两个音名是不是等音

---

### 第 2 章 · 音的长短

- **参考**：李重光 第二章（音符 / 休止符 / 附点 / 延音线 / 连音符）
- **核心概念**：音符时值体系、休止符、附点、延音线、连音符（三连音）
- **主实验台**：**时值时间轴**（切蛋糕）
- **玩法**：全音符当一整个蛋糕，切一刀变二分音符……；把块拖进小节，实时播放
- **挑战**：听一段节奏，选出正确的时值组合

---

### 第 3 章 · 节奏与节拍

- **参考**：李重光 第三章（节奏 / 节奏型 / 节拍 / 拍子 / 拍号 / 切分音 / 弱起小节）
- **核心概念**：拍与节奏、节拍、拍号（单拍子/复拍子）、强弱规律、切分音、弱起小节
- **主实验台**：**节奏网格 + 脉冲环**
- **玩法**：换拍号看重音梯度变化；点格子做鼓点；在 4/4 里放一个跨强拍的块，看到"错位"并听到切分
- **挑战**：判断拍号；找出切分位置
- **备注**：李重光把"节奏与节拍"放在音程之前。这个顺序有点闷但逻辑正确，
  建议保持，靠玩法把它变得不闷。

---

### 第 4 章 · 音程

- **参考**：李重光 第四章（音程 / 度数与音数 / 基本音程 / 自然音程与变化音程 / 单音程与复音程 / 音程的转位 / 等音程 / 协和音程与不协和音程）
- **核心概念**：度数（音级数）与音数（半音数）、性质（大/小/纯/增/减）、自然与变化音程、转位、协和度
- **主实验台**：**音程塔 + 波形干涉仪**
- **玩法**：拖两个音，看柱子高度差与中间台阶数；两条波形叠加显示拍频，
  拖到三全音时抖得最厉害——"最不协和"变成一个看得见的物理现象
- **挑战**：听辨音程性质；判断协和与不协和
- **备注**：这是 M1 的样板章节，因为它最能体现"具象化"的价值。

---

### 第 5 章 · 和弦

- **参考**：李重光 第五章（和弦 / 三和弦 / 七和弦 / 原位和弦与转位和弦 / 等和弦）
- **核心概念**：四种三和弦（大/小/增/减）、七和弦（属七、大七、小七、减七…）、转位、等和弦
- **主实验台**：**和弦堆叠台**
- **玩法**：从音块池往柱子上垒，系统自动命名；把底下的块扔到顶上就是转位；
  四种三和弦用黄/绿/陶土表达明亮的程度
- **挑战**：听辨三和弦性质；判断转位

---

### 第 6 章 · 调式与音阶

- **参考**：李重光（调式 / 音阶 / 调 / 大调式 / 小调式 / 调号 / 等音调；民族调式部分）
- **核心概念**：调式、音阶、主音、音级名称与罗马数字标记、大调式、小调式（自然/和声/旋律）、
  调号、关系大小调、五声调式
- **主实验台**：**调式引力场**
- **玩法**：拖动"引力中心"的位置，整条曲线变形，同一个旋律换一套表情；
  把五声音阶叠上去，看到缺了哪两级
- **挑战**：听辨大调/小调；给旋律判断调式

---

### 第 7 章 · 调式中的音程与和弦

- **参考**：李重光（调式中的音程 / 调式中的和弦）；功能和声入门（Open Music Theory 相应章节）
- **核心概念**：调内各级音程、正三和弦（I / IV / V）、副三和弦、属七和弦、终止式（V–I、IV–V–I）
- **主实验台**：**调内和弦地图**
- **玩法**：点亮一个音级，看到它上面叠出的和弦与功能标记；点 I–IV–V–I 看"回家"的路径动画
- **挑战**：给旋律选配和弦；听辨终止式

---

### 第 8 章 · 调性关系与转调

- **参考**：李重光（调性关系 / 转调 / 移调）
- **核心概念**：近关系调与远关系调、五度圈、离调与转调、移调
- **主实验台**：**五度圈罗盘**
- **玩法**：拖罗盘指针，听调性重心移动；点两个调，看到"旅行路线"和它们的共用和弦
- **挑战**：判断两个调的关系；给旋律移调

---

### 第 9 章 · 记谱法与常用记号

- **参考**：李重光（常用记号 / 装饰音 / 速度与力度术语 / 省略记号）
- **核心概念**：谱号、调号、拍号、省略记号、装饰音、力度与速度术语、演奏法记号
- **主实验台**：**谱面拆解** —— 点谱面上任何元素，弹出名称、含义，并播放实际效果
- **玩法**：装饰音直接听"加与不加"的差别
- **挑战**：速度术语排序；识别记号

## 4. 内容准确性怎么保证

乐理最容易错的地方是**调号、音程性质、和弦构成、等音**这些有明确计算规则的部分。

- 这部分在 `src/js/music/` 里写成**纯函数**（输入音名，输出性质），不掺 UI 代码
- 关键规则配断言测试：比如"G 大调调号必须是 1 个升号"、"B 到 F 必须是减五度"
- 听觉验证：生成的声音用真钢琴或调音器核对频率
