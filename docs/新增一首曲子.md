# 怎么给这个站加一首曲子

以 2026 年加的《Lateralus》（S 节）为样本，把流程写完整。
**照着做，不要跳步**——跳过第 2 步会写出"听起来差不多"的错误内容，跳过第 6 步会让编号断掉。

## 0 · 先想清楚这一节要教什么

一首曲子能讲的地方很多，但一节只能有一个中心论点。这个论点要能用一句话说出来，
而且必须**能用耳朵验算**。它的形状通常是：

> 把 X 做得不一样，听起来就变成了 Y。

已上线章节的论点：

| 节 | 曲子 | 一句话 |
| --- | --- | --- |
| R | King Crimson《Discipline》 | 没有一个人演奏完整的音乐 |
| S | Tool《Lateralus》 | 同一句话，装进越短的盒子 |
| O | 《三日月之舞》 | 独奏是曲子里唯一"一个人说话"的位置 |

论点先写在纸上，再开始查资料，**查资料是为了支撑论点，不是为了凑内容**。

## 1 · 起分支

```bash
git checkout main && git pull
git checkout -b codex/<曲名>
```

## 2 · 核事实（最花时间，也最不能省）

要拿到的东西：

- **元数据**：乐队／作曲、专辑、发行日期、录音时间、时长、成员与署名。
  优先用官方渠道、维基百科（标「需代理」）、MusicBrainz、流媒体的曲目数据；
  **两个独立来源对得上再写**。
- **音乐特征**：调性、拍号、速度、结构、编制。有谱就以谱为准；
  没谱就找**有出处**的描述（访谈、条目、乐评），并在页面上写明"这是资料的说法"。
- **一句可引用的原话**最好（作曲者／演奏者自己怎么说这首曲子）。

本站的规矩：**没有出处的数字不写**；有争议的说法（例如"歌词音节按斐波那契排列"）
要写明"官方没有确认"，并且**把它变成读者自己能验算的题目**。

## 3 · 决定它放哪儿、编号是多少

- 作品分析 → 第三部分（字母）；风格解析 → 第四部分（字母接着排）。
- 字母**按阅读顺序**排。往中间插一节，后面的字母要顺延，改三处：
  `src/js/music/curriculum.js` 的 `no`、页面里的 `<span class="crumb">`、`<p class="kicker">`。
  漏改会在审计里当场报错。

## 4 · 写实验台（如果这节需要）

实验台是这一节的"手"，读者靠它验算论点。动手前先问自己：

> 这个台子上的**哪一个动作**会让读者"啊"一声？

规则：

- 一个文件一个台，放 `src/js/widgets/<名字>-lab.js`，在 `src/js/main.js` 里注册；
- 素材一律是**本站自己写的示意**，页面上要明说；
- 出声前先 `stopAll()`；播放时必须有指示（按钮变亮／游标走／读数变）；
  这两条和另外几条已经被用户指出过的交互坑，完整清单在
  `CONTRIBUTING.md` 的「已经踩过的交互坑」，动手前扫一眼；
- 想让人反复播放的地方，**读数要跟着变**（例如"现在响的层 4/4"）；
- 关键数组 `export` 出去，交给审计。

## 5 · 写页面

页面结构已经固定，照现有长文抄骨架：

1. 开场（一个具体的、能勾住人的问题）
2. 资料卡 `<dl class="readout">`（出处、署名、时长、乐谱情况）
3. 逐段正文，每段一个副标题
4. 实验台 `<div class="card wide" data-widget="…"></div>` ＋ `<p class="hint">` 使用说明
5. 听点（4–6 条，每条都要能在录音里找到）
6. 参考（条目、访谈、合法试听链接；需代理的标注）
7. 一句话带走

写作要求：中文为主，术语首次出现给原文；速度用 BPM 不用"快一点"；
不确定的地方就写"我不确定"，不要糊过去。

## 6 · 把它接进课程

在 `curriculum.js` 对应层级加一行（`id / no / title / sub / status: 'ready'`），
顺延后面的字母，同步改那几页的 crumb 与 kicker。

## 7 · 给审计加防线

这一节引用的每个事实，尽量变成 `scripts/audit-music.mjs` 里的一条断言：

```js
eq(CYCLE.meters.join('-'), '9-8-7', '三种小节长度');
eq(CYCLE.alignAfter, 504, '三条循环重合一次的最小公倍数');
```

原则：**能被断言的东西不要靠人眼。** 过去犯过的错——级数当半音数、贝五动机少半音、
小鼓落错拍——最后都变成了断言。

## 8 · 交付

```bash
node scripts/audit-music.mjs      # 必须全绿
node scripts/check-links.mjs      # 外链体检
```

过一遍 `.github/pull_request_template.md` 的清单，
`git commit`（`feat: …`）、`git push -u origin <分支>`，开 PR。
