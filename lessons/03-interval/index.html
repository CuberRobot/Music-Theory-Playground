第 3 节 · 音程

两个音之间有多远

有了可以测量的音高坐标，距离才有意义。

音程就是两个音之间的距离。但麻烦在于，这个距离有两个量法： 跨了几个字母（度数），和差了几个半音（音数）。两个量都对，但回答的是不同的问题。

下面这个实验台可以让你同时看到这两个数字，然后在键盘上拖出一个反例—— 同一个黑键，换个名字就能从"小三度"变成"增二度"。

刚才发生了什么

度数：数的是字母。C 到 G 跨过 C D E F G 五个字母，所以是五度。 注意是"数到"，两头都算，所以 C 到 C 是一度而不是零度。

音数：数的是半音。C 到 G 是 7 个半音。C 到 C 是 0。

性质：同一度数下，音数还可以不一样，用大、小、纯、增、减来区分。 二度、三度、六度、七度有大小之分；一度、四度、五度、八度只有纯和增减， 没有"大五度"这种东西。

度数加性质，才是音程的完整名字。大三度、纯五度、增二度—— 这三个字里，一个字说度数，另外两个字说性质。

C→D♯ 和 C→E♭ 不是同一个音程

在钢琴上，D♯ 和 E♭ 是同一个黑键，同一个频率。但音程不是。

C 到 E♭ 是小三度：跨 C D E 三个字母，3 个半音。 C 到 D♯ 是增二度：跨 C D 两个字母，也是 3 个半音。 音数一样，度数不一样，所以性质也不一样。

听起来完全一样，为什么还要区分？因为在具体的调里，它们承担的功能不同。 大三度降半音就是小三度，这是把音阶里原有的音降低；而增二度通常是把某个音升高造成的， 它出现的场合往往是和声小调里那个著名的跳跃。写法不同，说明它从哪来、要往哪去。

这就是上一节说"等音名字不同、含义也不同"的后果。在实验台里把拼写切换到降号， 同一个键的名字和音程名会一起变。

单音程、复音程、转位

单音程是一个八度以内的音程。复音程超过一个八度， 九度、十度、十一度……判断性质时先减掉整八度，看剩下的单音程是什么。

转位是把下方音升高八度、或者把上方音降低八度，让两个音的关系翻过来。 规律很好记：度数相加等于 9，性质大小互换、纯还是纯、增减互换。

纯五度转位是纯四度（3:2 变成 4:3，正好是倒过来）。大三度转位是小六度。 这两个比例在上一节的泛音列里都出现过。

小结

  1. 音程有两个量：度数（数字母）和音数（数半音）。两者都要说，才算说清。
  2. 性质用大、小、纯、增、减表示。二三四六七度有大小，一四五八度只有纯和增减。
  3. 等音不是同一个音程：C→E♭ 是小三度，C→D♯ 是增二度。音数相同，度数和性质不同。
  4. 超过八度的是复音程，判断性质时先减掉整八度。
  5. 转位后度数相加等于 9，大小互换，纯仍是纯。
