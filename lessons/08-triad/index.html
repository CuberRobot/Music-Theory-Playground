第 8 节 · 三和弦

三个音叠起来

前面六节讲的都是单个音，或者两个音的关系。现在把三个音同时叠起来。

和弦不是一堆音随便凑的。最常见、也几乎是一切和声基础的，是三度叠置： 从一个根音出发，往上叠一个三度，再叠一个三度。

这两个三度各自可以是大的或小的，组合起来刚好得到四种三和弦。 下面这个实验台让你亲手改这两个三度，看和弦的名字怎么跟着变。

四种三和弦 = 两个三度的四种组合

和弦下面那个三度 上面那个三度听感
大三和弦大三度（4）小三度（3）明亮、稳
小三和弦小三度（3）大三度（4）柔和、暗
增三和弦大三度（4）大三度（4）悬着、不落地
减三和弦小三度（3）小三度（3）紧张、往下塌

括号里是半音数。注意一个对称：大和小是"两个三度交换位置"， 增和减是"两个都用大的"或"两个都用小的"。

口诀：是「下面那个三度」决定它是大还是小。 下面是大三度就是大三和弦，下面是小三度就是小三和弦——很多人记反，因为直觉会去看整体听感。

转位：同样的三个音，换个低音

把最低的那个音往上挪八度，构成音一个没变，但从下往上的顺序变了，这就是转位。 三和弦有三个位置。

中文的叫法有点特别：第一转位叫六和弦，第二转位叫四六和弦。 这些名字来自数字低音时代，说的是低音和上方音之间构成的音程度数。

转位不改变和弦的性质，但会改变它的稳定感。 原位最稳，第一转位最轻，第二转位最不稳、最想继续走。 所以选哪个转位，本质上是在选"这个和弦要有多想动"。

小结

  1. 三和弦 = 根音 + 三音 + 五音，由两个三度叠成。
  2. 四种性质来自两个三度的大小组合：大+小 = 大三和弦，小+大 = 小三和弦，大+大 = 增，小+小 = 减。
  3. 判断大小看下面那个三度，不是整体听感。
  4. 转位是换低音，不改变构成音，但改变稳定感。三个位置叫原位、六和弦、四六和弦。
  5. 越不稳的转位越"想往前走"，这是写和声进行时的重要工具。
