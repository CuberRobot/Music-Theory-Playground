第 11 节 · 调号与关系调

为什么需要一堆升号降号

上一节的大调结构是"全全半全全全半"。如果你从 C 开始弹，正好全落白键上。

但从 G 开始还按这个结构弹，就要用到 F♯；从 D 开始，要用到 F♯ 和 C♯。 每换一个主音，都会多出或者少掉一些升降号。为了避免在每个音前面都写一遍升降号， 人们把它们集中写在谱号后面，这就是调号。

把十二个调按升降号的数量排一排，会出现一件漂亮的事：它们正好围成一个圈。

五度圈是什么

从任何一个调出发，把主音往上移纯五度，新调就比原来的调多一个升号（或少一个降号）。 一直往上走十二次，会绕回出发的那个调。

C → G（1♯）→ D（2♯）→ A（3♯）→ E（4♯）→ B（5♯）→ F♯（6♯） → D♭（5♭）→ A♭（4♭）→ E♭（3♭）→ B♭（2♭）→ F（1♭）→ C。

升号的添加顺序是固定的：F C G D A E B。 降号的顺序正好是它的倒序：B E A D G C F。 这两个顺序不用背下来，在圈上顺时针走一遍就自然记住了。

为什么是五度而不是别的？因为五度是除了八度以外最"纯"的音程， 用它走一圈刚好能把十二个音走完一次、且只走一次。这是数学上的巧合， 也是整个西方调性体系的地基。

关系大小调

每个大调都有一个"共用同一批音"的小调，叫它的关系小调。 找出方法很简单：把主音往下移小三度。

C 大调的关系小调是 a 小调，G 大调的关系小调是 e 小调。 两者用完全相同的音、完全相同的调号，只是主音不同——

这又一次印证了上一节那句话：调式的差别不在用哪些音，而在谁是中心。 C 大调和 a 小调用的是同一批音，但一个明亮一个暗淡。

另外还有同主音大小调（也叫同名大小调）：C 大调和 c 小调，主音相同，音不同。 这两种关系是流行音乐里换情绪最常用的两招。

小结

  1. 调号把所有升降号集中写在谱号后面，避免每个音单独标。
  2. 每往上走一个纯五度，就多一个升号或少一个降号。
  3. 升号顺序 F C G D A E B，降号是它的倒序。
  4. 关系小调 = 主音往下小三度，和大调共用同一批音与同一个调号。
  5. 同主音大小调主音相同但音不同，是换情绪最常用的手段。
