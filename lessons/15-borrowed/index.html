第 15 节 · 借用与副属和弦

借颜色，和借方向

前十四节的调内和弦，全都在一个调里。这一节开始往外面拿东西。

有两种拿法，借到的东西完全不同：

借用和弦（modal mixture）从同主音的别的调式拿一个和弦过来，借的是颜色。 副属和弦（secondary dominant）给某个和弦临时装一个它专属的 V7，借的是方向。

分不清这两种的人，会把它们统称为"离调"，然后就再也不知道自己借的是什么了。

借用和弦：判定不用背表

第 13 节那张差分表在这里派上用场了。判定一个外来和弦"来自哪个调式"， 只要四步：

① 写出本调的七个音。② 写出想借的那个和弦的三个音。③ 看差在哪几个音上。 ④ 那些改动正好是某个调式的特征音。

特征音对照：♯4 → Lydian，♭7 → Mixolydian， ♭3♭6 → Aeolian，♭2 → Phrygian。

举个例子：Fm = F A♭ C。跟 C 大调的 F A C 比，多了个 ♭6 —— 所以 Fm 来自 Aeolian。要借一个 iv，就是去找 Aeolian 的这个 ♭6。

有一点要提醒：来源常常不唯一。B♭（B♭-D-F）在 Mixolydian 和 Aeolian 里都是本家。 所以"来自某调式"只是命名习惯，真正确定的事实是：它不在本调里，但在某某调式里。

副属和弦：给任意和弦装一个 V7

思路很直接：任何一个和弦都可以临时被当成"主"，那就给它配一个属七。

C 大调里最常用的四个：D7 → G（V/V）、A7 → Dm（V/ii）、 E7 → Am（V/vi）、C7 → F（V/IV）。

注意最后那个：C7 就是本调的主和弦加上一个小七度。 主和弦本来是终点，加上 ♭7 之后它变成了通往 IV 的起点 —— 同一组音，换了个身份。

副属和弦里那个♭7 是从外面借来的（C 大调里 B 应该是还原的）， 所以它一响，听者就知道"这里临时不是 C 大调了"。

和声自由化的第一条路

把前三节连起来看，其实是一张从"规矩"到"自由"的地图：

① 同功能替换（第 12 节：ii 替 IV、vi 替 I —— 引擎不变、表面变）→ ② 临时借力（本节：借用和弦换颜色、副属和弦换方向）→ ③ 换一种引力（三度关系，比如用大三度把八度三等分）→ ④ 取消引力（静态和声、持续低音、平行进行）。

绝大多数流行、摇滚、爵士的和声都在前两条里；三四条要到第二部分和风格解析再说。

小结

  1. 借用和弦借颜色（从别的调式拿），副属和弦借方向（给某和弦装 V7）。
  2. 判定借用和弦的来源：看它比本调多了哪些音，对应哪个调式的特征音。
  3. 特征音：♯4 = Lydian、♭7 = Mixolydian、♭3♭6 = Aeolian、♭2 = Phrygian。
  4. 来源常常不唯一，真正确定的是"它不在本调，但在某某调式里"。
  5. 副属和弦里那个 ♭7 是借来的，它一响就临时离开了本调。
