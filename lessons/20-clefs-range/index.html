第 20 节 · 谱号与音域

位置要有基准才有意义

第 19 节说"位置决定音高"。但位置本身是空的 —— 得先有谱号定基准。

谱号做的事只有一件：指定五条线里的某一条代表哪个音。 指定之后，其余位置就全都定下来了。

为什么需要好几种谱号？因为谱表只有五条线，能覆盖的范围有限。 给不同音区的乐器配不同的谱号，就能让它们都待在五线之内， 而不用写满加线 —— 加线多了，读谱会变得非常慢。

四种谱号，只差一件事

谱号它把哪个音定在哪谁在用
高音谱号 GG4 定在从下往上第二条线长笛、小提琴、吉他、女高音
低音谱号 FF3 定在从下往上第四条线大提琴、低音提琴、长号、男低音
中音谱号 C中央 C 定在第三条线中提琴
次中音谱号 C中央 C 定在第四条线大提琴与长号的高音区

两个 C 谱号的区别只是中央 C 坐在第几条线上。之所以需要它们， 是因为中提琴和大提琴的音区正好卡在高音谱号和低音谱号的接缝上 —— 用哪个都不舒服，所以专门给它们一个"中央 C 就在中间"的谱号。

音域：写曲子时最常犯的错

谱号解决"怎么读"，音域解决"谁来唱"。这两件事经常被混在一起， 结果是写出一段谁都没法演奏的东西。

实验台里那十二条是常见乐器与声部的实际音域。几条值得记住的：

长笛在最高，低音提琴在最低，两者之间隔了整整四个八度 —— 这就是为什么管弦乐能覆盖那么宽的范围。

木管五重奏为什么要塞一个圆号？因为纯木管组合缺厚度和低音支撑， 圆号填的正是那个空档。这说明音域不是一张表，而是一个需要配合的系统。

还有一个反直觉的地方：乐器的极限音区通常不好听。 长笛能吹到 C7，但那几个音又细又难控制；低声区同样吃力。 所以实际写作时用的范围，会比表上的音域窄一些 —— 表上写的是"能发出"，不是"适合用"。

小结

  1. 位置本身没有意义，谱号指定某一条线代表哪个音之后，其余位置才定下来。
  2. 高音谱号定 G4 在第二条线，低音谱号定 F3 在第四条线，两个 C 谱号定中央 C 的位置。
  3. 中音与次中音谱号是给卡在高音、低音谱号接缝上的乐器用的。
  4. 乐器能发出的音域 ≠ 适合使用的音域，两端通常不好听也不好控制。
  5. 配器不是查表，是让几件乐器的音域互相补位。
